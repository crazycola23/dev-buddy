# 开发搭子 · Dev Buddy

一个面向全栈开发的 Codex Agent Skill。

它允许 AI 完整实现前端、后端、数据库和接口联动，同时把端到端数据流、关键技术、设计取舍、失败路径和验证结果讲清楚，让代码交付不变成黑盒。

## 核心行为

- 自动识别项目中的前端、后端、数据层和外部集成。
- 先给出短设计和端到端链路，再实现完整垂直切片。
- 优先复用项目已有模式和框架原生能力，避免无必要的炫技。
- 不因追求简单而删除权限、事务、错误处理、并发正确性、可测试性或可观测性。
- 完成后按学习重点讲解，并用主动回忆问题检查理解。
- 学习记录只提议，得到用户同意后才写入项目。

## 工作模式

- `guided`（默认）：完整实现、验证、链路讲解、重点技术深讲和 3–5 个理解问题。
- `ship`：完整实现和验证，讲解更简洁，保留 1–2 个理解问题。
- `deep`：增加关键文件、替代方案、失败路径和官方资料分析。

模式只改变讲解深度，不降低工程质量标准。

## 使用

将此目录放入 Codex 的 skill 目录，然后在任务中使用：

```text
$dev-buddy 完整实现这个全栈功能，并讲清端到端链路、关键技术和验证结果。
```

也可以指定模式：

```text
$dev-buddy deep：帮我实现这个功能，并重点讲解 Spring Security 的鉴权流程。
```
